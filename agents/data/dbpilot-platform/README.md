# DBPilot - Natural Language Query Platform & Evaluation Framework

Welcome to **DBPilot**, an end-to-end system that allows users to query complex databases using natural language. This project features a beautiful split-screen UI for chatting with your data and a powerful backend powered by LangChain and DuckDB.

In addition to the core platform, this repository contains a comprehensive **Evaluation Framework**. This framework is designed to automatically generate synthetic data, create Q&A test pairs, and rigorously evaluate the AI's performance using both deterministic checks and an LLM-as-a-Judge.

---

## 🏗️ Project Architecture

The project is split into three main components:

1. **Frontend (The Client)**: A stunning, glassmorphism-styled Vanilla HTML/CSS/JS application. It runs directly in the browser with no build step required.
2. **Backend (The API)**: A FastAPI Python server that handles the LangChain pipeline (Schema Extraction -> SQL Generation -> Execution -> Answer Synthesis).
3. **Evaluation Framework (The Tester)**: A suite of Python scripts that generate synthetic DuckDB datasets and automate the testing of the NLQ Platform to catch regressions.

---

## 📂 Directory Structure

Here is a detailed breakdown of what you will find in this repository:

### `backend/` - The Backend Core
Contains the FastAPI server and LangChain agents that power the platform.
* `api/endpoints.py`: The FastAPI routes that receive requests from the frontend or the evaluator.
* `pipeline/agents.py`: The LangChain setup using `gpt-5.1` to turn natural language into SQL.
* `pipeline/executor.py`: Connects to DuckDB to safely execute the generated SQL.
* `pipeline/schema_extractor.py`: Reads the target DuckDB file to understand the tables and columns.
* `models/`: Contains Pydantic data schemas to ensure the API receives properly typed data.

### `frontend/` - The User Interface
A sleek, zero-dependency web interface.
* `index.html`: The main dashboard containing the connection screen and the chat interface.
* `style.css`: Premium glassmorphism styling, floating background animations, and layout grids.
* `script.js`: Handles API requests (`fetch`) to the backend, updates the chat history, and renders the live data table and SQL debugger.

### `eval/` - The Evaluation Framework
Scripts for testing the accuracy of the AI.
* `generate_datasets.py`: Programmatically generates complex, synthetic DuckDB databases for 3 specific domains (Device Management, IT Ops, and E-Commerce). It intentionally injects imperfections like duplicate rows, NULLs, and boundary dates to test the AI's robustness.
* `generate_qa.py`: Systematically generates exactly 100 Q&A pairs for each domain, mapped precisely to 5 tiers of SQL complexity (from simple aggregations to 3-table JOINs).
* `orchestrator.py`: The test runner. It reads the Q&A pairs, sends them to the running `app/` API, and records the results.
* `llm_judge.py`: Uses an LLM to evaluate the generated answers on a 4-dimensional scale (Factual Correctness, Completeness, Format Adherence, and SQL Plausibility).

### `datasets/` - Data Storage
* Contains the `.duckdb` databases and the `qa_pairs.csv` files generated by the `eval/` scripts. 
* *Note: Run `python eval/generate_datasets.py` and `python eval/generate_qa.py` to populate this folder!*

## 🚀 Setup & Installation

### 1. Environment Variables
You must provide an OpenAI API key for the LangChain pipeline and the LLM Judge to work.
1. Create or edit the `.env` file at the root of the project.
2. Add your API key:
   ```env
   OPENAI_API_KEY="sk-proj-..."
   ```

### 2. Python Environment Setup
Open a terminal at the root of the project and run the following to install the backend requirements:

```bash
# Create and activate a virtual environment
python -m venv .venv

# On Windows:
.\.venv\Scripts\Activate.ps1
# On Mac/Linux:
# source .venv/bin/activate

# Install the dependencies
pip install -r requirements.txt
```

### 3. Generate the Test Data
Before using the platform, generate the synthetic databases and Q&A pairs:

```bash
python eval/generate_datasets.py
python eval/generate_qa.py
```
This will populate the `datasets/` folder with realistic scenarios.

---

## 🎮 Running the Application

Because the frontend is served directly by the FastAPI backend, you only need to run a single command!

**Start the Server:**
```bash
# From the root directory with your virtual environment activated:
uvicorn main:app --reload
```

**Open the UI:**
Once the server starts, open your web browser and navigate to:
👉 **http://localhost:8000/**

You will see the gorgeous NLQ Platform connection screen!

## 💡 How to Use the Platform

1. **Connect to a Database**: 
   - When the UI loads, it will ask for a Database Path. 
   - Use one of the generated dummy datasets! Just copy-paste this path: `datasets/domain_1_device_mgmt/db.duckdb`
   - Click **Connect**.

2. **Chat with Data**:
   - In the left panel, ask a question like *"How many active devices do we have?"* or *"List all events for devices assigned to the Engineering department."*
   - The AI Assistant will process your request.
   - The **Live Data Table** on the right will dynamically populate with the raw SQL results.
   - Click the **Generated SQL** banner at the bottom to inspect the exact DuckDB query the AI wrote!

3. **Navigate**:
   - Use the **Home** button in the top right to disconnect and try another database (like `datasets/domain_4_ecommerce/db.duckdb`).
