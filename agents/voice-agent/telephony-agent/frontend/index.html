Call flow

Caller → Plivo or browser mic → FastAPI, over a WebSocket (μ-law 8 kHz). AssemblyAI transcribes, Sarvam 105B answers, TTS speaks each sentence. Audio returns on the same socket; speaking over it cancels the reply.
