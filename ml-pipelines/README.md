# ML Pipelines

Classical machine-learning and NLP pipelines: data preparation, model training, evaluation, serialization, and inference.

| Project | Source | Purpose | Status |
|---|---|---|---|
| [financial/financial-ai-pipelines](financial/financial-ai-pipelines) | [GitHub](https://github.com/suraj636/Financial--AI-Pipelines) | Three scikit-learn pipelines for credit-risk classification, credit-score regression, and customer segmentation, with preprocessing, baselines, metrics, joblib artifacts, and inference scripts. | Implemented |
| [nlp/comment-polarity-analyzer](nlp/comment-polarity-analyzer) | [GitHub](https://github.com/suraj636/CommentPolarityAnalyzer) | TensorFlow/Keras BiLSTM multi-label toxic-comment classifier trained on Jigsaw data, with a Gradio demo. | Implemented |
| [nlp/sentiment-analysis-social-media](nlp/sentiment-analysis-social-media) | [GitHub](https://github.com/suraj636/SentimentAnalysisOnSocialMediaPosts) | Depression-text classification using NLTK preprocessing, TF-IDF features, and Naive Bayes/Random Forest models. | Implemented |
| [nlp/textual-analysis-articles](nlp/textual-analysis-articles) | [GitHub](https://github.com/suraj636/TextualAnalysisOnArticles) | Web-scraping and NLP text analytics pipeline computing sentiment polarity, readability (Fog Index), word statistics, and pronoun counts into a structured CSV. | Implemented |
| [recommenders/recommendation-systems](recommenders/recommendation-systems) | [GitHub](https://github.com/suraj636/Recommendation_Systems) | Two recommender notebooks: movie content similarity with CountVectorizer and cosine similarity, plus a book popularity/collaborative-filtering recommender. | Implemented |

## Subcategories

- `financial/` — financial-services ML workflows.
- `nlp/` — task-specific natural-language processing pipelines.
- `recommenders/` — recommendation and ranking systems.
