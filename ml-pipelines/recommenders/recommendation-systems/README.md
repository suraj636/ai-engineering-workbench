# Recommender Systems (Books & Movies)

This repository contains two Jupyter notebooks demonstrating how to build **content-based recommender systems** using **core NLP techniques** and **vector embeddings**.

## Notebooks

* 📘 **`book-recommender-system.ipynb`** → Recommends books based on textual similarity of metadata (titles, authors, descriptions).
* 🎬 **`Movie_Recommender_System.ipynb`** → Recommends movies using plot summaries, genres, and other text features.

## Techniques Used

* **Text preprocessing**: tokenization, stopword removal, stemming/lemmatization
* **Feature extraction**: TF-IDF & vector embeddings
* **Similarity measures**: Cosine Similarity for recommendation ranking
* **Content-based filtering**: Recommendations based on item-to-item similarity
